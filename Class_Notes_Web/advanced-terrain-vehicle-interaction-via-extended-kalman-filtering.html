1. Introduction: The Spatial-Temporal Dichotomy in Vehicle State Estimation

A fundamental challenge in the simulation and state estimation of multibody vehicles traversing rough terrain—such as a bicycle on an unpaved trail—lies in a dimensional mismatch. The vehicle is a temporal dynamic system, evolving second by second according to the laws of motion. The terrain, however, is a spatial static field, varying meter by meter.

When a vehicle's front wheel impacts a perturbation, that same spatial perturbation will strike the rear wheel at a future time. A naive approach to modeling this within a state estimator involves augmenting the state vector with a massive discrete time-delay buffer (a shift register). However, this introduces severe computational and mathematical flaws. If the vehicle's advancing velocity fluctuates, the required delay becomes fractional, necessitating complex temporal interpolation. Worse, if the vehicle stops, the temporal delay approaches infinity, causing the state dimension to explode and the filter's covariance matrix to collapse.

To handle terrain roughness robustly, we must abandon the time-delay paradigm. Instead, we separate the problem: we maintain a purely instantaneous probabilistic state vector within the filter, and delegate the physical "memory" to a deterministic, purely spatial map updated sequentially by the front wheel.

Because we have explicitly defined the spatial statistical properties of the terrain , and because the Kriging operation is a deterministic linear transformation, the statistical correlation between at step and step is mathematically observable a priori.

We do not need the filter to estimate the parameters of a shaping filter for the rear wheel in real-time. Instead, we analytically derive the autocorrelation sequence of the Kriging error based on the known terrain frequency and sampling distance, effectively bypassing the computational burden of real-time parameter identification for the rear-wheel noise.

6. Advancing to the Generalized EKF (GEKF)

While the standard EKF gracefully handles the nonlinearities of the kinematic Jacobians and , embedding the terrain's statistical parameters () directly into the state vector creates volatile, non-Gaussian cross-correlations. The Jacobians of the state transition become highly sensitive; a poor initial guess for spatial frequency can cause the prediction matrices to collapse.

A superior alternative is the Generalized Extended Kalman Filter (GEKF). The filter is treating the terrain's spatial frequency and variance as dynamic states, but these variables are used to model noise covariances. The GEKF is a superior choice in this context.

8.3 Simplifying the GEKF: The Dual Kalman Filter (The Decoupling Hypothesis)

While the full augmented GEKF provides the mathematically optimal estimate (under linearisation), it is computationally demanding. Propagating the full covariance matrix and calculating the tensors at high frequencies for a multibody simulation can be prohibitive. However, by viewing the GEKF as the foundational algorithm, we can derive adaptive filtering simplifications.

If we assume that the uncertainty in the terrain parameters does not heavily influence the instantaneous state update, we can impose the Decoupling Hypothesis: we force the cross-covariance to zero (). By doing this, the massive GEKF shatters into two distinct, parallel filters:

  1. The State Filter: Computes the state update assuming is perfectly known.
  2. The Parameter Filter: Computes the parameter update using a sensitivity matrix .

This is the Dual Kalman Filter. It treats the state innovation as a pseudo-measurement for the terrain parameters. It requires less memory and matrix inversion while still propagating the parameter uncertainty , making it an excellent middle-ground for real-time multibody vehicle control.

Handling Stochastic Non-Idealities via State Augmentation

The fundamental assumption of the standard Information Kalman Filter framework is that the epistemic uncertainties—specifically the process modeling error and the sensor equation error —are strictly independent, zero-mean white noise sequences. Furthermore, it assumes that the random variables representing these errors are entirely uncorrelated with one another.

In complex dynamic systems, this idealization frequently breaks down. We generally categorize these breakdowns into two types of correlation:

  1. Spatial Correlation: A statistical dependency across different physical components (e.g., between a process disturbance and a sensor error).
  2. Temporal Correlation: A statistical dependency across sequential time steps, either because a noise source has "memory" (colored noise) or because an input noise creates a feedback loop across the update-predict boundary.

To maintain the strict optimality of the estimator without breaking the foundational assumptions of the filter, we rely on State Augmentation. By elevating our mathematical ignorance into the state vector, we transform correlated and non-white physical realities back into mathematically standard epistemic problems.
